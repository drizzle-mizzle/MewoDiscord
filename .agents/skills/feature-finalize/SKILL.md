# Feature Finalize

Работай из корня репозитория и соблюдай `CLAUDE.md`.

## Обязательный цикл

1. Изучи `git status` и текущий diff. Не удаляй и не перезаписывай чужие изменения.
2. Запусти:

   ```bash
   bash .agents/skills/feature-finalize/scripts/finalize.sh
   ```

   Если `dotnet` или `docker` не находятся в PATH, передай полные пути через переменные `DOTNET` и `DOCKER`. Не запускай боевого бота, `docker compose up` и сетевые тесты `АИ_*`.
3. При ошибке исправь исходники, конфигурацию или безопасную локальную причину сбоя. После каждого исправления повтори **весь** скрипт. Не исправляй глобальные настройки машины без явного согласия.
4. Не считай точечный `csc`, старую DLL, пропуск Docker или просмотр diff заменой соответствующей проверке. Если SDK, NuGet или Docker недоступны, сообщи точный блокер; не заявляй успешную финализацию и не push как проверенные изменения.
5. После успешного прогона проверь `git diff --check`, итоговый diff и обновления `CLAUDE.md`/`README.md`. Убедись, что форматтер не внёс нежелательных unrelated-правок, а секреты и временные файлы не попали в Git.
6. Только теперь коммить и push, если это требовалось исходным запросом или правилами репозитория. После успешного push дай однострочную команду обновления из `CLAUDE.md`.

## Критерий завершения

Финализация завершена только при нулевом коде всех шагов скрипта. Любой пропущенный, failed или недоступный шаг — незавершённая финализация, а не предупреждение, которое можно проигнорировать.
